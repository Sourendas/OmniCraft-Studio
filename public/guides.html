Guides

These articles explain how each job works in this browser tab, including the cases where it will not work. They are written by Souren Das in Bengaluru for the tools on this site. FileTools Kit does not run an upload API that receives your documents. Questions: support@filetoolskit.com.

If you only needed the tool, the links inside each guide open it. If a PDF is encrypted, huge, or signed, read when browser PDF tools fail before you try a site that asks you to upload.

All guides

  • Merge PDF files in the browser — Combine a cover letter, resume, and certificates. Page copy with pdf-lib, not an upload.
  • Split a PDF by page range — Copy pages such as 2-4 or 1-3,5. The original file is not rewritten.
  • Compress a PDF in the tab — A light object-stream rewrite. Not a server optimizer, and scans may not shrink.
  • Turn PDF pages into JPG — Rasterize pages for a form that wants images. No OCR.
  • Put JPG and PNG scans into one PDF — One page per image. Shrink images first if a portal caps size.
  • Reorder or delete PDF pages — Move pages, drop blanks, download a new file.
  • Password-protect a PDF — What an open password does here, and why you must test it in another reader.
  • Add page numbers — Stamp a simple page label after you merge, not before.
  • Convert PNG, JPG, and WebP — Canvas re-encode in the tab. HEIC and AVIF are not a pipeline.
  • Compress images — Scale and re-save. No guaranteed percent.
  • Build a resume PDF — Form, layouts, and a local keyword overlap that is not an employer ATS.
  • Resume PDF checklist — Pre-send checks: selectable text, no sample copy, filename, packet order.
  • Create a QR code — PNG or SVG in the tab. No short link and no scan analytics.
  • Hash text with SHA-256 — Web Crypto in the tab. A hash is not encryption.
  • What stays in this tab — What is processed locally, what the host can still see, what ads do not receive.
  • When browser PDF tools fail — Encryption, memory, signatures, scans, and when to stop.
  • JPG, PNG, or WebP — Which file to send for email, WhatsApp, and upload forms.
  • Watermark vs password vs redaction — A stamp is not a lock, and this site does not redact.

About these pages

Each guide states the library in use (pdf-lib, canvas, or Web Crypto), the steps, and the limits: no OCR, no guaranteed compress percent, no employer ATS, no redaction. Each guide shows the date of its last edit. Corrections: support@filetoolskit.com.
