Password-protect a PDF in the browser

Password Protect PDF tries to save a copy that asks for a password before it opens. The work runs in this tab. FileTools Kit does not store the password on a server we operate.

Test the download in a normal PDF reader before you rely on it. If the reader opens the file with no prompt, the protection did not stick. Use a desktop tool you trust for anything that must stay locked.

A password stops a casual open. It is not a watermark, and a watermark is not a password. Do not use this page to remove a password from a file you do not have the right to open.

  1. Open Password Protect PDF and add a PDF that is not already encrypted.
  2. Set a password you can remember. The page does not email it to you.
  3. Download and open the file in a reader. Confirm the prompt appears.
