How to password-protect a PDF in the browser

Password Protect encrypts a PDF with AES-256 so another reader asks for the password you chose. The password and the file stay in this tab. FileTools Kit does not keep a copy and cannot reset a forgotten password. Write the password down somewhere you control before you close the tab.

What a password is not

A watermark is overlay text. Someone can cover it. Encryption is the lock on this page. Neither one is redaction. Text under a black box can still be copied if you only drew a stamp. This site does not redact.

Already-encrypted files often cannot be re-saved here. Unlock them in a reader you trust, then protect the unlocked copy if you still need a password.

Steps

  1. Open Password Protect PDF.
  2. Pick the PDF and choose a password of at least 6 characters. Type it again in the confirm box.
  3. Download and open the file in a second PDF reader. If it opens without asking, the lock did not apply. Do not send that copy.

How the lock is set

The same password is used to open the file and as the owner password. In most readers, typing it gives full owner access, so anyone who can open the file can also print, copy, and edit it. This page does not offer separate permission settings such as print-only. The download is named after the original with -protected added, so offer.pdf becomes offer-protected.pdf, and the original stays unlocked on your disk.

Length matters more than symbols. Anyone who has the file can try passwords offline as fast as their computer allows. Use a long passphrase, four or five unrelated words, and send it by a different route from the file, for example a phone call or a text message if the PDF went by email.
