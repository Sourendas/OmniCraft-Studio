How to password-protect a PDF in the browser

Last updated 10 October 2026 · Written by Souren Das

Password Protect encrypts a PDF with AES-256 so any reader asks for the password you chose before showing a page. The password and the file stay in this tab. FileTools Kit does not keep a copy and cannot reset a forgotten password, so write the password down somewhere you control before you close the tab.

When a password makes sense

Use one when a file with personal or financial details travels through channels you do not control: an email that may be forwarded, a shared drive, a chat group, or a USB stick. Payslips, bank statements, Form 16, medical reports, an offer letter, and ID scans are typical. Many Indian banks already send statements this way, locked with a password built from your date of birth or customer ID, for the same reason.

A password does not help when the receiver needs to upload the file to a portal: most portals reject encrypted PDFs. Ask before you lock a file meant for an application form.

Steps

  1. Finish every other change first: merge, organize, page numbers. An encrypted file cannot be edited here afterwards.
  2. Open Password Protect and press Choose a PDF.
  3. Type a password of at least 6 characters, and the same in Confirm password. Show password lets you check what you typed. The page tells you if the two do not match.
  4. Press Protect PDF. The page says it is encrypting with AES-256, then downloads a copy named after your file with -protected added, so offer.pdf becomes offer-protected.pdf.
  5. Open the protected copy in a second reader, for example a different browser or your phone. It should ask for the password. If it opens without asking, do not send that copy.
  6. Send the file, and send the password by a different route.

Choosing a password that holds up

Anyone who has the file can try passwords offline, as fast as their computer allows, with no lockout after three attempts. Length beats symbols. Six characters is the minimum the page accepts, not a recommendation. A passphrase of four or five unrelated words, such as mango-ladder-quiet-river, is long, easy to read out on a call, and much harder to guess than P@ss123. Avoid your date of birth, phone number, or PAN alone; they are the first things a person who knows you would try.

Sending the password

If the PDF goes by email, the password should not be in the same email or the next email in the thread, because whoever gets one gets both. Read it out on a call, send it by SMS or a messaging app, or agree a rule in advance with a regular contact. For a document the receiver must open many times, tell them to save the password in their password manager.

How the lock is set

The same password is used to open the file and as the owner password. In most readers, typing it gives full owner access, so anyone who can open the file can also print, copy, and edit it. This page does not offer separate permission settings such as print-only, and those restrictions are weak in practice anyway, because many tools ignore them. The original stays unlocked on your disk, which is what you want for your own copy.

Common mistakes and fixes

  • This PDF already has a password. Remove it in your PDF reader first (open it, then save or print an unlocked copy), then protect that copy.
  • Forgot the password. There is no password recovery. Go back to the unlocked original and protect it again.
  • Portal rejected the file. Upload the unlocked original to the portal; portals usually need to read the file.
  • Locked the original by mistake. You cannot: the original is never changed. Only the -protected copy is locked.

What a password is not

A watermark is overlay text. Encryption is the lock on this page. Neither one is redaction: once someone opens the file with the password, every word is there. If a number must not reach the receiver at all, remove it from the source document before making the PDF. The differences are laid out in watermark, password, and redaction are different.

Privacy

Encryption runs in this tab with a pdf-lib build that supports it, loaded only on this page. The password is never sent anywhere. See what stays in the tab.

FAQ

Can FileTools Kit remove a password from a PDF?

No. Use the reader that can open it, then save an unlocked copy.

Will the receiver need special software?

No. Current browsers, Adobe Acrobat Reader, and phone PDF viewers open AES-256 PDFs and ask for the password.

Does encryption change the file size?

Barely. The content is encrypted, not recompressed.

Can I set a print-only or no-copy permission?

Not here. One password opens and owns the file.
