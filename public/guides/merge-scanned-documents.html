How to merge scanned documents into one PDF

Last updated 10 October 2026 · Written by Souren Das

Scanned paperwork rarely arrives as one tidy file. You might have a PDF the office emailed last year, a few pages your scanner saved as separate files, and two pages you photographed on your phone this morning. This guide shows how to turn that mix into one PDF in the right order, with sideways pages fixed and blank pages removed, without uploading the documents anywhere.

Why combine scans at all

Reviewers, landlords, HR teams, and visa offices often ask for "one PDF" because it is easier to file and harder to lose a page. A single file in the order the checklist asks for also makes your application look careful. Merge only what belongs together, though. If a portal has a separate upload field for each document, keep them separate.

What you need

  • Any PDFs you already have.
  • Any photos or scanner images as JPEG or PNG.
  • A browser on a computer or phone. A computer is easier for long documents.

The tools used are JPG to PDF, Merge PDF, and Organize PDF. All three run in the same tab.

Step 1: turn photos into a PDF

Merge PDF only accepts PDFs, so loose images go through JPG to PDF first.

  1. If the photos are large (most phone photos are), shrink them in Image Optimizer with Output Format set to JPEG and Dimensions Scaling around 40 percent. This keeps the merged file small enough to email.
  2. Open JPG to PDF and press Choose JPEG or PNG files. Select the images. Name them 01, 02, 03 beforehand so they are placed in that order.
  3. images.pdf downloads. Rename it to something like photos-part.pdf so you can tell it apart from the others.

Step 2: merge the PDFs in order

  1. Open Merge PDF. This is PDF Suite set up for merging.
  2. Add the PDFs in the order you want them to appear. Drop them in or click to browse. Each file shows as a card with its first page and page count.
  3. If a whole file is sideways, press its Rotate +90° button until it is upright. Rotation applies to every page of that file.
  4. If a file is in the wrong position, remove it with the trash icon and add it again at the end. There is no drag-to-reorder in this list.
  5. Press Merge PDFs. The result downloads as merged.pdf.

Pages are copied, not redrawn, so the merge does not reduce quality. Text in digital PDFs stays selectable.

Step 3: tidy individual pages

Merging works on whole files. To fix single pages, open merged.pdf in Organize PDF:

  • Delete blank pages. Double-sided scanning of single-sided paper leaves blank backs. Select them and press Delete selected.
  • Rotate single pages. A page fed upside down can be turned 90 degrees at a time with its own rotate button.
  • Move pages. Use the move buttons on a thumbnail to place a signature page or an annexure where it belongs.

Press Export organized PDF. The new file is named after the original with -organized added. The file you opened is not changed.

Step 4: number and check

For a long packet, page numbers help the reader refer to a page. Run the file through Add page numbers as the last step, because numbers are drawn on the page and move with it if you reorder later. Then open the final file and check the first page, the last page, and any page you rotated.

Keeping the size down

A merged file is roughly the sum of its parts. If one scan is 8 MB, the merged file will be at least 8 MB. Find the heavy file first by looking at the sizes in your file manager, and shrink that one. For scanned PDFs, the reliable method is to turn the pages into images with PDF to JPG at Screen (108 DPI), shrink the images, and rebuild with JPG to PDF. The upload portal guide explains this in detail. The light re-save in Compress PDF rarely helps scans, because it does not recompress images.

Common mistakes

  • Adding files in the wrong order. The merge follows the list from top to bottom. Plan the order before you add files, or fix it afterwards in Organize PDF.
  • Merging a password-protected PDF. Encrypted files usually fail. Open the file with its password in your reader, save or print an unprotected copy, and use that.
  • Expecting bookmarks to survive. Bookmarks, outlines, and form fields from the source files may not carry over.
  • Mixed page sizes. A4 scans and Letter-size PDFs stay their own size. This looks odd when scrolling but does not affect reading or printing with "Fit to page".
  • Running out of memory on a phone. Very large scans can stall a mobile browser. Merge in smaller groups, or use a computer.

Privacy

Scanned documents often carry ID numbers, addresses, and signatures. Merge PDF, Organize PDF, and JPG to PDF read and write the files inside your browser with pdf-lib. FileTools Kit does not run an upload API for them, and nothing is stored after you close the tab. FAQ

Is there a limit on how many files I can merge?

There is no fixed limit. The practical limit is your device's memory. On a phone, merge in batches of a few files.

Can I merge images and PDFs in one step?

No. Turn the images into a PDF first with JPG to PDF, then merge.

Will merging make the scans clearer?

No. Merging copies pages exactly. It cannot sharpen a blurry scan.

Can I undo a merge?

Your original files are unchanged. To pull pages back out of the merged file, use Split PDF with a page range.
