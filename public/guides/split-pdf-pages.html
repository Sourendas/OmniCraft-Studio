How to split a PDF by page range in your browser

Split is the other half of merge. You have one long PDF and you only need pages 3–7, or page 1 plus page 12. FileTools Kit PDF Suite reads the first file in the list with the browser File API, copies the pages you name into a new document with pdf-lib, and starts a download. The original file on disk is not rewritten.

FileTools Kit does not run an upload API that stores that PDF. Encrypted files often fail in the browser.

When to use split

Use split to extract a certificate from a scanned bundle or send only the appendix a clerk asked for. Do not use split to redact words on a page you keep. Do not use it on a password-protected file.

Step-by-step

  1. Open PDF Suite and add the PDF. Split uses the first file in the list.
  2. Open Split / Range and type a 1-based range such as 1-3,5.
  3. Export and open the download. Check the first and last page you expected.
