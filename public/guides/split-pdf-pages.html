How to split a PDF by page range

Last updated 10 October 2026 · Written by Souren Das

Split is the opposite of merge. You name the pages you want, and Split PDF copies those pages into a new PDF. The file you picked is not rewritten on disk. FileTools Kit does this with pdf-lib in the tab, and there is no upload step.

When splitting is the right job

  • An office asked for the signed page only, not the whole 30-page agreement.
  • A bank statement download covers six months and the form wants the last three.
  • One scan session produced a single PDF holding two different documents, such as a degree certificate and a mark sheet, and a portal wants them as separate uploads.
  • A long file is too heavy for a portal, and the receiver only needs part of it.

If you want to keep every page but change the order, use Organize PDF. If you want to drop one blank page from the middle of a file, Organize is also quicker, because you can see the thumbnails.

Steps

  1. Open Split PDF. The Split / Range tab is already selected on the right.
  2. Drop the PDF on the dashed box or click to browse. Split uses the first file in the list, so if you loaded others, remove them with the bin icon or press Clear All and start again.
  3. Read the page count on the file card, for example 12 page(s). That tells you the highest number you can use.
  4. Type the pages in Page range (first loaded file), for example 2-4 or 1-3,5.
  5. Press Export split PDF. The new file downloads as split-pages.pdf and a message confirms how many pages it took.
  6. Open the download and check the first and last page before you rename and send it.

How ranges work

Commas separate parts and a hyphen marks a run, so 2-4,7,9-10 keeps six pages. Spaces are fine. The numbers are the order of pages in the file, starting at 1, not the numbers printed in a footer. If a scan has a cover as its first page, the page with footer number 3 is page 4 of the file. Your PDF reader shows the file position in its page box, which is the number to use.

Pages always come out in file order, and a page listed twice appears once, so 5,1-3 gives pages 1, 2, 3, and 5, in that order. A backwards run such as 4-2 is read as 2-4. Numbers past the end of the file are ignored, so 10-99 on a 12-page file gives pages 10, 11, and 12. If nothing valid is left, the page tells you instead of downloading an empty file. When you need pages in a different order, split first and then fix the order in Organize PDF.

Cutting one file into several parts

Each export makes one file. To cut a 12-page file into three documents, run the split three times with 1-4, then 5-9, then 10-12. Every download is called split-pages.pdf, and browsers add (1), (2) to repeats, so rename each one as soon as it lands, for example degree-certificate.pdf and marksheet-sem1.pdf. Renaming as you go avoids sending the wrong part later.

A worked example

Say a college sends a 9-page PDF: page 1 is a covering letter, pages 2 and 3 are the provisional certificate, and pages 4 to 9 are semester mark sheets. A job portal wants the certificate and the final-year mark sheets (pages 8 and 9) as one upload. Type 2-3,8-9, export, and open the file: it should have four pages, certificate first. If the portal also caps size, check the file size before uploading and see the size guide if it is too large.

Common mistakes and fixes

  • The wrong pages came out. You used footer numbers. Count from the first page of the file instead.
  • It split the wrong document. Split always uses the first card. Clear the list and load only the file you want.
  • "Split failed." The file is often encrypted. Save an unlocked copy in your reader and try again.
  • The download is as big as the original. Large scanned pages stay large. Splitting removes pages, it does not shrink the ones you keep.

What split will not do

It will not OCR a scan, redact a sentence, or remove a password. It will not split by bookmarks or headings, and it does not cut every N pages automatically. Bookmarks and form fields from the source are not carried into the new file, and a digital signature on the original will not be valid in the extract. If the tab stalls on a very large scan, try a smaller range first.

Privacy

The PDF is read into this tab and the extract is built there. Nothing is sent to a FileTools Kit server. Closing the tab clears the loaded file; your download stays in your downloads folder. More detail in what stays in the tab.

FAQ

Can I extract a single page?

Yes. Type just that number, for example 4.

Is the text still selectable in the new file?

Yes, if it was selectable in the original. Pages are copied, not rendered as images.

How do I delete pages instead of choosing pages to keep?

Type the ranges you want to keep around the unwanted page. To drop page 5 from a 10-page file, type 1-4,6-10. Or delete it visually in Organize PDF.

Can I split several PDFs at once?

No. One file, one range per export.
