How to split a PDF by page range

Split is the opposite of merge. You name the pages you want, and the tool copies those pages into a new PDF. The file you picked is not rewritten on disk. FileTools Kit does this with pdf-lib in the tab. There is no upload step.

How ranges work

A range like 1-3,5 keeps pages 1, 2, 3, and 5. Numbers are the order of pages in the file, not a label printed in the footer. If a scan was saved with a cover as page 1, the signature you want may be page 4 even if the footer says 3.

Use split when an office asked for the signature page only, or when one download mixed two documents. If you need to reorder rather than drop pages, use Organize PDF.

Steps

  1. Open Split PDF.
  2. Pick the PDF. Split uses the first file in the list, so remove any others you loaded. Encrypted files often fail. Unlock them first.
  3. Type the range. Check the page count the tool shows against the file you opened.
  4. Download the new PDF and open it before you send it.

Range details

Commas separate parts and a hyphen marks a run, so 2-4,7,9-10 keeps six pages. Pages are always exported in file order, and a page listed twice appears once, so 5,1-3 gives pages 1, 2, 3, and 5. Numbers past the end of the file are ignored. If nothing valid is left, the page says so instead of downloading an empty file. The download is named split-pages.pdf.

To cut one file into several parts, run split once per part: 1-4, then 5-9, then 10-12, and rename each download as you go.

What this will not do

It will not OCR a scan, redact a sentence, or remove a password. It will not split by heading. If the tab stalls on a very large scan, extract a smaller range first.
