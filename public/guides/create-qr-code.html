How to create a QR code and export PNG or SVG

QR Generator encodes a link, Wi-Fi details, a contact card, an email address, or a short line of text, and exports PNG or SVG. The code is drawn in this tab. FileTools Kit does not host a redirect behind it and does not count scans. The code points at the address you typed, nothing else.

Before you print

Use a URL you have already opened in a browser. A long payload makes a dense code that a phone camera misses. If the address changes later, a printed code still points at the old one. SVG is the better export for a print shop. PNG is enough for a slide.

Leave a quiet margin around the code. A logo in the middle is not added here. If you need one, export SVG and edit it in SVG Studio, then scan again. A broken scan after a logo is common.

Steps

  1. Open QR Generator.
  2. Paste a short https URL.
  3. Export SVG for print or PNG for a deck.
  4. Scan the export with your own phone before you print a stack.

What each type puts in the code

A URL is stored as typed. Wi-Fi stores the network name, the password, and the security type in the format phone cameras read, so the phone offers to join the network. Characters such as a semicolon, comma, colon, or quote in the name or password are escaped as that format requires. A vCard stores a name, phone number, email, and organisation, and the phone offers to save the contact. Email Draft stores a mailto link with your address and the subject Contact. Text stores the words and nothing else.

Error correction, colors, and margin

Error correction decides how much of the code can be damaged and still scan: about 7% at L, 15% at M, 25% at Q, and 30% at H. H is the default and suits print, where a fold or a smudge is likely. Higher levels make a denser code, so for a long payload on a small sticker, M can scan better. Keep a dark foreground on a light background. Inverted or low-contrast colors fail on some scanners. Leave the margin at 2 or more, because scanners need that quiet border to find the code.
