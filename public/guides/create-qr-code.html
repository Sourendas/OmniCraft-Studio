Create a QR code and export PNG or SVG

QR Generator encodes a URL or short string and lets you export PNG or SVG. Pixels are drawn in this tab. FileTools Kit does not host a redirect short-link behind the code.

  1. Type a short https URL you have already opened.
  2. Generate the preview.
  3. Export SVG for print or PNG for slides.
  4. Scan the export with your phone before you print flyers.

Long payloads make dense codes that cheap cameras miss. If the URL changes later, printed codes still point at the old address.
