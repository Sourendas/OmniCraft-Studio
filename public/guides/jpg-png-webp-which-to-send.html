JPG, PNG, or WebP: which file to send

Last updated: 1 October 2026 · Souren Das, FileTools Kit, Bengaluru.

The format argument is usually a destination constraint. This is the rule of thumb I use with the converter and optimizer on this site.

Send JPEG when

The form says JPG. The picture is a photo. The recipient is on an old phone or a government portal. JPEG has no transparency.

Send PNG when

You need sharp UI text, a screenshot, or transparency. If email rejects it, scale the long edge down before you switch to JPEG.

Send WebP when

The site accepts it. Do not send WebP to a form that lists only JPG and PNG.

Chat apps recompress images again. For a document, send a PDF if the app allows it. For a photo, 1600 pixels on the long edge is enough to read a form on a phone. HEIC from some iPhones will not decode here. Export JPEG from the phone first.
