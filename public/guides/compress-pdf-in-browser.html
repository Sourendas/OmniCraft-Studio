Compress a PDF in the browser, without pretending it always shrinks

Compress PDF on FileTools Kit is a light rewrite. The page copies pages into a new document and saves them with object streams. That can shrink some files. Image-heavy scans often barely change. This is not a server optimizer that recompresses every embedded photo.

I state the limit on the page because a tool that promises a tiny file and then returns the same scan is worse than a tool that tells you what it did. Keep the original until you have compared sizes.

When a light rewrite is enough

Use it when a PDF was saved with unused objects, or when you want a clean copy without uploading the file. Do not use it when the only reason the file is large is a stack of phone photos already saved as tight JPEGs.

Step by step

  1. Open Compress PDF.
  2. Choose one PDF. Encrypted files often fail.
  3. Download the result and compare the file size to the original.
  4. If the size barely moved and you needed a smaller photo, use Image Optimizer on the pictures first, then build a new PDF from those images.

This page will not OCR a scan, repair a corrupt file, or turn the PDF into Word. FileTools Kit does not run an upload API for the PDF you pick here.
