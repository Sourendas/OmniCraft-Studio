How to reorder, rotate, and delete PDF pages

Organize PDF shows page thumbnails so you can drag a packet into the right order, rotate a sideways scan, or drop a blank page. Export writes a new PDF. The file you opened is not edited on disk. The work runs in this tab with no upload API.

Order of jobs

Reorder before you add page numbers. Numbers stamped first will be wrong after you move pages. If you only need a range and the rest can go, Split PDF is faster than deleting one page at a time.

Steps

  1. Open Organize PDF.
  2. Wait for thumbnails. A long scan uses more tab memory because each page is drawn here.
  3. Drag a thumbnail to move it. Click thumbnails to select them, then use Rotate selected or Delete selected. Deleting removes the page from the download only. Your original remains until you delete it yourself.
  4. Export and open the new file before you send it.

Encrypted files often fail to open. If the tab slows, split the file first and organize the smaller part.

How the controls behave

Each click on Rotate selected turns the chosen pages 90 degrees clockwise, so a page that is upside down needs two clicks. Select all and Clear selection save clicking through a long file. Delete selected is disabled when every page is selected, because a PDF needs at least one page. The bar above the grid shows how many pages are left and how many are selected, which is a quick check before you export.

The download is named after your file with -organized added, so report.pdf becomes report-organized.pdf. Rotation is saved as a page setting, the same way a desktop reader rotates a page, so the content is not redrawn or blurred.

Large files

Every thumbnail is drawn in this tab, so a 300-page scan takes a while and uses memory. Above 150 pages the tool warns you. On a phone or an older laptop, split the file into parts with Split PDF, organize each part, and merge them back with Merge PDF.
