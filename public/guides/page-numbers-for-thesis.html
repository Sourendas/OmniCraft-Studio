How to add page numbers to a thesis or project report PDF

Last updated 10 October 2026 · Written by Souren Das

Most universities in India and elsewhere want the same thing from a thesis or project report: the title page and certificates unnumbered, and the chapters numbered from 1. Word processors can do this with section breaks, but that is fiddly, and sometimes all you have is the final PDF your lab partner exported. This guide shows how to number a finished PDF so that page 1 is where the first chapter starts, using tools that run in your browser.

Check your guidelines first

Your department's formatting guide decides where the number goes, what style it uses, and which pages carry one. Common rules include numbers centred at the bottom, Arabic numerals (1, 2, 3) from the first chapter, and lower-case Roman numerals (i, ii, iii) for the front matter. Read the guide before you start.

Be aware of what the tool here can and cannot do. Add page numbers draws Arabic numbers in one of three positions: Bottom centre, Bottom right, or Top centre. It offers three formats: 1, 1 / N, and Page 1 of N. It numbers every page of the file you give it. It does not do Roman numerals, and it cannot skip pages within a file. The method below works around the skipping. If your guidelines require Roman numerals on the front matter, number the source document in Word or LaTeX instead.

If you still have the Word or Google Docs file

Numbering in the source is the cleanest option. Insert a section break after the front matter, unlink the footer of the chapter section from the previous one, and start numbering at 1 there. Then export to PDF. The rest of this guide is for when you only have the PDF, or when the source numbering keeps going wrong.

The method in four steps

The idea is simple: cut the PDF into the part that should not be numbered and the part that should, number the second part, and join them again.

Say your thesis is 86 pages. Pages 1 to 8 are the title page, certificate, declaration, acknowledgements, abstract, and contents. Chapter 1 starts on page 9.

  1. Split off the chapters. Open Split PDF, load the thesis, open the Split / Range tab, type 9-86, and press Export split PDF. Rename the download from split-pages.pdf to chapters.pdf.
  2. Split off the front matter. Back in Split PDF, with the same thesis loaded, type 1-8 and export again. Rename this one front.pdf.
  3. Number the chapters. Open Add page numbers. Leave Start at at 1, choose the Position and Format your guidelines ask for, then press Choose PDF files and pick chapters.pdf. The numbered file downloads as page-numbers.pdf, and the status line confirms the range, for example "Numbered 78 page(s), 1 to 78."
  4. Join the two parts. Open Merge PDF, add front.pdf first and page-numbers.pdf second, and press Merge PDFs. The final thesis downloads as merged.pdf. Rename it to the name your department wants.

Choose the options before you pick the file in step 3, because the numbering runs as soon as the file is chosen.

Variations

Numbering from a page other than 1

Some reports count the front matter in the total but only print numbers from the introduction. In the example above that would mean the introduction shows 9. Set Start at to 9 in step 3.

Chapters in separate files

If each chapter is its own PDF, you can pick them all at once in step 3. The tool joins them and numbers them as one continuous run. Pages are taken in the order your browser's file picker returns the files, which is usually alphabetical, so name them 01-introduction.pdf, 02-literature.pdf, and so on. Open the result and check that chapter order is right.

Appendices without numbers

Split the appendices off as a third part and add it after page-numbers.pdf in the merge.

About the "of N" formats

In the 1 / N and Page 1 of N formats, N is the last number printed, not the number of pages in your file. With Start at 1 on 78 pages, the last page reads Page 78 of 78, as you would expect. With Start at 9, the last page reads Page 86 of 86. A thesis normally uses the plain 1 format.

Common mistakes

  • Numbering before the content is final. The numbers are drawn on the pages. If you add a figure later and pages shift, you have to redo the numbering from an un-numbered copy. Keep chapters.pdf without numbers so you can redo step 3.
  • Numbers overlapping an existing footer. If the PDF already has a footer, such as a running title, the new number may sit on top of it. The number is placed 18 points (about 6 mm) from the edge in 10-point Helvetica. Try Top centre instead, or remove the footer in the source.
  • Wrong page range in the split. The numbers you type are positions in the file, not printed page numbers. Open the PDF and check which file page the first chapter is on.
  • Table of contents does not match. If your contents page lists chapter 1 on page 1, the numbering above matches. If it lists page 9, use Start at 9. Check two or three entries against the final file.
  • Encrypted PDFs. If the PDF has a password, the tools stop with "Encrypted PDFs often fail." Save an unprotected copy first.

Final checks before submission

  • Open merged.pdf and confirm the title page has no number and chapter 1 starts at the right number.
  • Jump to the last page and confirm the final number.
  • Check a landscape page, if you have any. The number is centred on that page's own width.
  • Check the file size against the submission portal's limit. Splitting, numbering, and merging copy pages without re-rendering them, so the size stays close to the original.

FAQ

Can I use Roman numerals for the front matter?

Not with this tool. It prints Arabic numbers only. Use your word processor's page number formatting for that.

Can I change the font size of the numbers?

No. The size is fixed at 10 points, which suits A4 and Letter pages.

Does this reduce the quality of my figures?

No. Pages are copied as they are. Only the number is added on top.

Can I remove numbers after adding them?

Not from the numbered file. Go back to the copy you saved without numbers.
