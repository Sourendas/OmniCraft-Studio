How to make a Wi-Fi QR code guests can scan

Last updated 10 October 2026 · Written by Souren Das

Reading out a Wi-Fi password to every guest gets old quickly, especially when it is sixteen random characters printed on the back of a router. A Wi-Fi QR code lets anyone join by pointing a phone camera at it. This guide explains how these codes work, how to make one in QR Generator, how big to print it, and what to think about before you stick your password on a wall.

How a Wi-Fi QR code works

The code holds a short line of text in a format phones recognise, for example WIFI:T:WPA;S:HomeNetwork;P:mypassword;; where T is the security type, S is the network name (SSID), and P is the password. Current iPhone and Android camera apps read this and offer to join the network. Nothing is looked up online: the network name and password are inside the code itself.

That has two consequences. The code works without internet, and it never expires. It also means anyone who can see the code can read the password, which matters for the privacy section below.

What you need before you start

  • The exact network name. It is case-sensitive. "HomeWiFi" and "homewifi" are different networks. Copy it from your router's label or settings page.
  • The exact password. Also case-sensitive.
  • The security type. Almost every home and office network today uses WPA2 or WPA3. Check the router settings if unsure. Choose open only if the network truly has no password.

Step by step

  1. Open QR Generator and choose Wi-Fi Network.
  2. Type the network name in Network SSID Name.
  3. Type the password in Password. The field shows the text openly so you can check it, so do this away from onlookers.
  4. Set Encryption Protocol. Choose WPA / WPA2 / WPA3 for nearly all networks, WEP only for very old equipment, or Open (No Password) for networks without a password.
  5. Leave the colours dark on light. The default is navy on white, which scans well.
  6. Leave Error Correction at H unless your password is very long. H lets the code survive about 30 percent damage, which helps for a printed sign that may get scratched or partly covered.
  7. Keep Quiet Margin at 2 or more.
  8. Test it now: point your phone's camera at the preview on screen. It should offer to join the network. Try a second phone if you have one, ideally one Android and one iPhone.
  9. Press Download PNG for screens and quick printing, or Vector SVG for sharp printing at any size.

Special characters in passwords

The Wi-Fi format uses semicolons, colons, commas, quotes, and backslashes as separators. If your password contains any of these, they must be "escaped" with a backslash or phones misread the password. QR Generator does this for you. You type the password exactly as it is, and the code contains the escaped version. Test it on a phone anyway.

Printing it

  • Size: a code about 3 to 4 cm wide scans easily from a table card held in the hand. For a sign on a wall read from a metre or two away, go to 10 cm or larger. As a rough rule, the scanning distance can be about ten times the width of the code.
  • Use the SVG for print. It stays sharp at any size. The PNG is 320 pixels, fine for a small card but soft on a poster.
  • Add a line of text. Write the network name and "Scan to join Wi-Fi" next to the code, so people know what it is, and so anyone whose camera does not scan it can still join by hand.
  • Avoid glossy lamination under bright lights. Glare can stop a phone reading the code. Matte paper is easier.

Common problems and fixes

  • The phone scans but fails to connect. Usually a typo in the network name or password, or the wrong security type. Check each against the router, including capital letters and spaces at the end.
  • The phone does not react at all. Some older Android phones need Google Lens or a QR app rather than the camera. Make sure the code has good contrast and a margin around it.
  • It worked yesterday but not today. Someone changed the Wi-Fi password, or the router's network name. Make a new code; printed codes cannot be edited.
  • Hidden networks. QR Generator does not set the hidden-network flag. If your network does not broadcast its name, some phones will not find it from the code. Join it manually instead.
  • 5 GHz and 2.4 GHz with different names. Each name is a separate network and needs its own code.

Privacy and security

A Wi-Fi QR code is your password in a different form. Anyone who photographs it can read the password with any QR app. Think about where you put it:

  • At home, a code inside the house, on the fridge or a card in a drawer, is fine for most people.
  • For a shop, café, or office, use a separate guest network that cannot reach your own computers, printers, and cameras. Most routers offer a guest network setting. Put the guest network's code on display, never the main one.
  • Change the guest password now and then and print a new code.

QR Generator builds the code in your browser tab. The network name and password are not sent to FileTools Kit, and nothing is saved after you close the tab. The default text in the fields is example data; replace all of it.

FAQ

Does the code need internet to work?

No. The details are inside the code. The phone only needs to be in range of the network.

Will it expire?

No. It keeps working until you change the network name or password.

Can I put my logo in the middle?

QR Generator does not add logos. Covering part of a code with a logo relies on error correction and can make it harder to scan.

Can I see who scanned it?

No. A Wi-Fi code has no tracking. Your router's admin page may list connected devices.
