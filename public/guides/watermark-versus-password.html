Watermark, password, and redaction are different

Last updated 10 October 2026 · Written by Souren Das

These three jobs get mixed up on PDF sites, and the mix-up has real costs: a salary slip sent "protected" by a CONFIDENTIAL stamp, or an ID number "hidden" under a black box that anyone can lift off. They are not interchangeable, and FileTools Kit only does two of them. This page explains each one, how to check it worked, and which to pick.

Watermark: a visible label

A watermark draws text, often CONFIDENTIAL, DRAFT, or a person's name, on top of each page. Anyone can still read everything underneath. It is a label that says how the document should be treated, and it can discourage casual forwarding or show which copy leaked. It is not encryption and it does not remove anything.

On this site, the watermark lives in the PDF Suite. Load the PDFs, open the Watermark tab, set Watermark text, Opacity, and Font size, and press Export annotated PDF. The text is drawn diagonally across the middle of every page in orange, and the file downloads as annotated.pdf. Opacity runs from 5% to 80% and starts at 30%, which is readable without hiding the page. Because the stamp is ordinary page content, a determined person with a PDF editor can delete it; treat it as a notice, not a barrier.

Password: a lock on opening

A password encrypts the file so a reader must type it before it shows any page. Without the password the content is unreadable, which makes this the right tool for a file travelling by email or a shared folder. Once the receiver types it, they can read, copy, and print everything. Password Protect uses AES-256 in this tab, and the steps, passphrase advice, and how to send the password are in the password guide.

Test it. Open the protected copy in a second reader; it should ask for the password. FileTools Kit cannot recover a password you forget, because the file never came to us.

Redaction: permanent removal

Redaction means the hidden text is gone from the file, not merely covered. A black rectangle drawn on top of an Aadhaar number, in any editor that only adds shapes, leaves the number in the text layer underneath. Someone can select it, copy it, or delete the rectangle. Proper redaction tools remove the text and image data under the box and then flatten the page.

This site does not offer redaction. Do not use a watermark or a drawn box as a stand-in for hiding an Aadhaar number, a bank account, or a salary figure.

How to check a "redacted" file you received or made

  1. Open the PDF and drag-select across the black box. If text highlights, it is still there.
  2. Copy the selection and paste it into a plain note. If the hidden number appears, it was never removed.
  3. Use the reader's search for a digit sequence you know is under the box.

If any of those reveal the text, the file is not redacted.

What to use

  • Label a draft or mark a copy: watermark.
  • Stop someone without the password from opening it: password, then test it.
  • Make sure the receiver never sees a number: remove it from the source before you make the PDF, or use a dedicated redaction tool. Not this site.
  • Both a label and a lock: watermark first in the PDF Suite, then protect the annotated file.

Practical safer routes for redaction

If you made the document, edit the source (the Word file or spreadsheet), delete the sensitive value, and export a fresh PDF. For a scan, you can turn the page into an image with PDF to JPG, paint over the area in an image editor so the pixels themselves change, and rebuild the PDF with JPG to PDF. For a scan there is no hidden text layer, so changing the pixels does remove the information. Check the result with the steps above.

Common mistakes

  • Telling the receiver a file is "secured" when it only carries a stamp.
  • Sending the password in the same email as the file.
  • Highlighting text in black in a word processor and exporting to PDF. The text is still there.
  • Watermarking a document the receiver must upload to a portal; the stamp can make it look tampered.

Say what you did

If you watermarked, write: "The file is not locked. CONFIDENTIAL is a stamp on the page." If you passworded and tested: "The file should ask for a password. I will send the password separately."

Privacy

Both the watermark and the password run in this tab. The PDF and the password are not sent to a FileTools Kit server.

FAQ

Can a watermark be removed?

Yes, with a PDF editor. It is a label, not protection.

Is a password-protected PDF safe to email?

Reasonably, with a long passphrase sent another way. A short password can be guessed offline.

Will FileTools Kit add redaction?

Not at the moment. Doing it properly in a browser is hard, and a half-working version would be worse than none.
