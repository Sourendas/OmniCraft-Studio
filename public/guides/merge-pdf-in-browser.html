How to merge PDF files in your browser

Last updated 10 October 2026 · Written by Souren Das

Merging is the job of putting a cover letter, a resume, and a few certificates into the single attachment a portal or an HR inbox asked for. Merge PDF on FileTools Kit does that copy in the tab you already have open. It reads each PDF with the browser File API, copies the pages into a new document with pdf-lib, and offers a download. It does not run an upload API that receives those PDFs.

When to merge, and when not to

Merge when you have two or more PDFs and the receiver wants one file. Typical cases: a job application (cover letter, resume, then certificates), a reimbursement claim (form first, then bills), or a visa or admission packet where the checklist names an order. The merged file follows the list on the page, and the list is the order you added files.

Do not merge when you only need some pages. That is Split PDF. Do not merge when you need to reorder single pages inside a file. That is Organize PDF. And do not merge password-protected files here: the merge reads each file without a password, so an encrypted PDF usually fails. Unlock it in a reader you trust, save an unlocked copy, and merge that.

Steps

  1. Open Merge PDF. It is the same page as the PDF Suite, opened for merging.
  2. Drop the PDFs on the dashed box or click it to browse. You can pick several at once and add more later. Each file becomes a card.
  3. Check the order. Each card shows Order #1, #2, and so on, a thumbnail of page 1, the page count, and the size in KB. There is no drag-to-reorder on this page. To move a file to the end, remove it with the bin icon and add it again.
  4. Fix sideways files. Rotate +90° on a card turns every page of that file a quarter turn clockwise. Press it twice for upside down.
  5. Press Merge PDFs above the cards. The file is built in memory and downloads as merged.pdf. Your originals on disk are not touched.
  6. Open merged.pdf and scroll through it. The cards only preview page 1 of each file, so the download is where you confirm the middle pages.

Getting the order right the first time

Because moving a file means removing and re-adding it, the quickest route is to add files in the final order. If you pick several files in one go, the browser decides the order it hands them over, which is usually the order you selected but not always. Two habits avoid surprises: add files one at a time in the order the receiver expects, or rename them first with a number prefix such as 01-cover-letter.pdf, 02-resume.pdf, 03-degree.pdf and add them together. Then glance at the Order numbers before you press Merge PDFs.

If one file needs pages moved inside it, for example an appendix that came out of the scanner backwards, fix that file in Organize PDF first and merge the organized copy.

Rotate, watermark, and document details

Rotation from the card is saved as a page setting when you merge, the same way a desktop reader rotates a page, so nothing is redrawn or blurred. To rotate one page out of twenty, use Organize PDF instead, because the card rotates the whole file.

Export annotated PDF, at the top right, merges the same list and also stamps the Watermark text diagonally across the middle of every page in orange, at the Opacity and Font size you set (30% and 36 pt to start). It also writes the Title, Author, Subject, and Keywords from the Metadata tab into the file. The starting values are generic (Title: Processed document, Author: FileTools Kit), so change them to your own before you export, or leave the plain merge alone. If the watermark text is empty, the export merges and sets the details only. That download is annotated.pdf. A watermark is a visible label, not a lock and not redaction; see watermark, password, and redaction.

How big will the merged file be?

Roughly the sizes of the inputs added together, because the pages are copied as they are. Merging does not compress images. If three 900 KB scans must go to a portal with a 2 MB cap, merging gives you a file near 2.7 MB and the portal will still refuse it. Shrink first, then merge. The guide to getting a PDF under 1 MB or 200 KB walks through the image route that actually reduces scans.

Common mistakes and fixes

  • "Could not read that PDF." The file is usually encrypted or damaged. Open it in your reader. If it asks for a password, save an unlocked copy first.
  • Wrong file in the packet. Two downloads called scan.pdf look alike. Check the page count and thumbnail on each card before merging.
  • Page numbers that restart. If each source has its own printed numbers, the merged file will show 1, 2, 1, 2, 3. Number the merged file afterwards with Page Numbers.
  • The tab stalls on big scans. Each scan page can be a large image. Merge in batches of a few files, then merge the batches.
  • Refreshed the tab mid-way. A reload clears the cards. Downloads you already saved stay in your downloads folder.

What a merge can break

A digitally signed PDF loses a valid signature after any rewrite, even when the page looks the same. Send a signed original as its own attachment. Bookmarks in a reader's side panel are not carried into the merged file, and fillable form fields may not survive, so fill and flatten a form before you merge it if you can. Links between pages inside a source file may stop working.

Privacy

The PDFs are read into this tab's memory and the merged file is built there. FileTools Kit does not receive the bytes. The site itself still loads from Vercel and shows Google ads, which is explained in what "files stay in this tab" means.

FAQ

How many files can I merge?

There is no fixed count. The limit is your device's memory. A dozen text PDFs is easy. Fifty phone scans on an older phone may stall, so batch them.

Can I merge JPG photos with a PDF?

Not directly. Turn the photos into a PDF with JPG to PDF, then merge that PDF with the others.

Does the merged file keep selectable text?

Yes, if the sources had it. Pages are copied, not turned into pictures. A scan stays a picture of text.

Can I undo a merge?

Your originals are untouched. If you need parts back from merged.pdf, use Split PDF with the page range.
