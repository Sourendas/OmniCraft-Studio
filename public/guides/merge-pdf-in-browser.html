How to merge PDF files in your browser

Merging is the job of putting a cover sheet, an appendix, and a form into one file a portal will accept. FileTools Kit does that copy in the tab you already have open. The tool reads each PDF with the browser File API, copies pages into a new document with pdf-lib, and offers a download. It does not run an upload API that receives those PDFs.

When to merge

Merge when you have two or more PDFs and the receiver asked for one attachment. A common case is a job application: cover letter, resume, then certificates, in that order. The merged file follows the list, and the list is the order you added files, so add them in the order the receiver expects.

Do not merge if you only need a subset of pages. That is split. Do not merge if the files are password-protected. Encrypted PDFs often fail in the browser. Unlock them in a reader you trust, then merge the unlocked copies.

Steps

  1. Open Merge PDF or the PDF Suite.
  2. Drop or pick the PDFs. The browser stores them as File objects in this tab.
  3. Check the order. There is no drag-to-reorder in the suite. To move a file to the end, remove it and add it again. Each card shows page 1 and the page count, which helps you spot the wrong file.
  4. Press Merge PDFs. The new file is built in memory and downloads as merged.pdf. The originals on disk are not overwritten.
  5. Optional watermark. Default text is CONFIDENTIAL. That is overlay text, not encryption and not redaction.

Rotate, watermark, and document details

The rotate button on a file card turns every page of that file 90 degrees clockwise per click, and the rotation is applied when you merge. Use it for a scan that came in sideways. To rotate single pages, use Organize PDF instead.

Export annotated PDF merges the same list and also stamps the watermark text diagonally across the middle of every page, in orange, at the opacity and size you set (30% and 36 point by default). It also writes the title, author, subject, and keywords from the Metadata tab into the file. The starting values are generic, such as the author FileTools Kit, so change them to your own details before you export. If you leave the watermark text empty, the export only merges and sets the details. The download is annotated.pdf.

What fails

A signed PDF may lose a valid signature after any rewrite. A scan that is one huge image per page can stall the tab. If that happens, merge in smaller batches, then merge the batches. A reload drops the in-memory files. Downloads you already saved stay in your downloads folder.

Page numbers stamped before a merge will be wrong if each source started at 1. Number the combined file after, with page numbers.
