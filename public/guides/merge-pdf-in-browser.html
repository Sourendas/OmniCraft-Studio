How to merge PDF files in your browser

Merging PDFs is a common chore: a cover sheet, an appendix, and a form that need to travel as one file. FileTools Kit does that merge in the tab you already have open. The PDF Suite reads each file with the browser File API, copies pages into a new document with pdf-lib, and lets you download the result. FileTools Kit does not run an upload API that receives those PDFs.

Last updated: 3 September 2026 · Souren Das, FileTools Kit, Bengaluru

When to use this tool

Use merge when you have two or more PDFs and want one file to send, print, or archive.

Skip merge if you only need a subset of pages — that is split. Skip it if the PDFs are password-protected; encrypted files often fail in the browser.

Step-by-step

  1. Open the PDF Suite. From the home page, open PDF Suite.
  2. Drop or pick the PDFs. The browser stores them as File objects in this tab.
  3. Order the files. Merged output follows the list order.
  4. Merge and download. The tool builds a new PDF in memory.
  5. Optional watermark. Default text is CONFIDENTIAL. That is overlay text, not encryption.
