How to merge PDF files in your browser

Merging is the job of putting a cover sheet, an appendix, and a form into one file a portal will accept. FileTools Kit does that copy in the tab you already have open. The tool reads each PDF with the browser File API, copies pages into a new document with pdf-lib, and offers a download. It does not run an upload API that receives those PDFs.

When to merge

Merge when you have two or more PDFs and the receiver asked for one attachment. A common case is a job application: cover letter, resume, then certificates, in that order. Merged output follows the list order, so set the order before you click.

Do not merge if you only need a subset of pages. That is split. Do not merge if the files are password-protected. Encrypted PDFs often fail in the browser. Unlock them in a reader you trust, then merge the unlocked copies.

Steps

  1. Open Merge PDF or the PDF Suite.
  2. Drop or pick the PDFs. The browser stores them as File objects in this tab.
  3. Order the files. The download follows that list.
  4. Merge and download. The new file is built in memory. The originals on disk are not overwritten.
  5. Optional watermark. Default text is CONFIDENTIAL. That is overlay text, not encryption and not redaction.

What fails

A signed PDF may lose a valid signature after any rewrite. A scan that is one huge image per page can stall the tab. If that happens, merge in smaller batches, then merge the batches. A reload drops the in-memory files. Downloads you already saved stay in your downloads folder.

Page numbers stamped before a merge will be wrong if each source started at 1. Number the combined file after, with page numbers.
