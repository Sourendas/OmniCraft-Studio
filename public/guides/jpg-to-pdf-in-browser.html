How to put JPG and PNG scans into one PDF

A rent receipt, an ID photo, and a signed form often start as images. JPG to PDF places each image on its own page and downloads one PDF. The photos stay in this tab. There is no account and no upload API.

Before you start

Export HEIC from a newer iPhone as JPEG first. This page does not convert HEIC. Very large photos make a heavy PDF. If a portal caps the upload, shrink the images in Image Optimizer before you build the PDF.

The PDF is a picture of each image. Text in the photo is not selectable. No OCR runs here. If the receiver needs selectable text, this export will not create it.

Steps

  1. Open JPG to PDF.
  2. Pick the JPEG or PNG images. Pages follow the order the browser hands the files over, which is usually the order you selected. If order matters, name the files 01, 02, 03 first.
  3. Build and download. Open the PDF and check rotation. A sideways photo stays sideways unless you rotate it first.

Page size and output

Each image becomes one page the size of the image, one point per pixel. A 1200 by 1600 photo makes a large page, but readers scale it to fit the screen, and a print dialog's fit-to-page option handles paper. The download is named images.pdf. Rename it before you send it, for example rent-receipts-may.pdf, so the receiver knows what it is.

Sideways photos

Phones often save a photo as stored pixels plus a rotation flag that the gallery app respects. This tool places the stored pixels as they are, so a photo that looks upright in your gallery can come out sideways. If that happens, rotate the photo in the gallery and save it again before you build the PDF, or fix the page afterwards in Organize PDF.
