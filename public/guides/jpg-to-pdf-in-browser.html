How to put JPG and PNG scans into one PDF

Last updated 10 October 2026 · Written by Souren Das

A rent receipt, an ID photo, and a signed form often start life as images on a phone. JPG to PDF places each image on its own page and downloads one PDF. The photos stay in this tab. There is no account and no upload API.

This guide covers how the tool behaves. If you are starting from phone photos for an application form, the companion guide turn phone photos of documents into a PDF for an online form covers taking the photos, cropping, and size caps in more depth.

When to use it

  • A form wants one PDF and you have several photos or screenshots.
  • A receiver cannot open image attachments but can open a PDF.
  • You want a set of receipts or bills in a fixed order in one file for a claim.
  • You exported pages as images and want them back as a PDF after editing them.

Before you start

Only JPEG and PNG are accepted. A newer iPhone saves photos as HEIC, so export or share them as JPEG first (on iPhone, setting the camera format to Most Compatible saves JPEG from then on). WebP, GIF, and HEIC files are refused with the message Use JPEG or PNG only.

Very large photos make a heavy PDF, because each photo goes in unchanged. If a portal caps the upload, shrink the images in Image Optimizer first. The result is a picture of each page, so text in the photo is not selectable and no OCR runs here.

Steps

  1. Name the files in the order you want, for example 01-form.jpg, 02-receipt.jpg, 03-id.png. This is the easiest way to control page order.
  2. Open JPG to PDF and press Choose JPEG or PNG files.
  3. Select all the images in one go. The PDF is built as soon as you confirm the picker, and images.pdf downloads. The page says, for example, Built a 3-page PDF.
  4. Open images.pdf. Check the page order and that no page is sideways.
  5. Rename it to something the receiver will understand, such as rent-receipts-may.pdf.

Pages follow the order the browser hands the files over. That is usually the order you selected, and on most systems a multi-select in a sorted folder comes through in name order, which is why numbered names help. There is no reorder step on this page. If the order comes out wrong, fix it in Organize PDF or rename the files and build again.

Page size and output

Each image becomes one page the size of the image, one point per pixel, with no margin. A 1200 by 1600 photo makes a large page, but PDF readers scale it to fit the screen and a print dialog's fit-to-page option handles paper. Images of different shapes make pages of different shapes, which is normal for scans. There is no option to force A4 or add white borders.

The file size is roughly the total of the images plus a small amount for the PDF structure, because JPEGs are embedded as they are. Twelve 3 MB phone photos make a PDF of about 36 MB. Shrinking to around 1600 pixels on the long side and quality 70 in Image Optimizer usually brings each page to a few hundred KB while keeping text readable.

Sideways photos

Phones often save a photo as stored pixels plus a rotation flag that the gallery app respects. This tool places the stored pixels as they are, so a photo that looks upright in your gallery can come out sideways. Three fixes, easiest first:

  • Rotate the page afterwards in Organize PDF with Rotate selected.
  • Run the photos through Image Optimizer first. It redraws each image the way the browser displays it, and saves a copy without the flag.
  • Rotate the photo in the gallery and save it, then build the PDF again.

Common mistakes and fixes

  • Only one page came out. You picked one file. Select all images together in the picker; picking again builds a new PDF rather than adding to the last one.
  • Use JPEG or PNG only. One of the files is HEIC, WebP, or misnamed. Convert it with File Converter (WebP to JPG works there) or export it as JPEG.
  • The PDF is huge. Shrink the photos first, then build again.
  • Dark, tilted photos. The tool cannot straighten or brighten. Retake the photo flat, in daylight, with the page filling the frame.
  • PNG screenshots made a big file. PNG is lossless. Convert screenshots of photos to JPEG; keep PNG for screenshots of text.

Privacy

The images are read in this tab and the PDF is built there. Nothing is sent to a FileTools Kit server. That makes it a sensible choice for ID cards and bank documents, though the PDF you make is only as private as wherever you send it next. Details in what stays in the tab.

FAQ

Can I add more images to a PDF I already made?

Build a second PDF from the new images, then join the two with Merge PDF.

Will the text in my photo be searchable?

No. The page is a picture. Searchable text needs OCR, which this site does not do.

Does it reduce image quality?

No. JPEG and PNG data are embedded unchanged. That is why the file can be large.

Can I make A4 pages?

Not here. Page size follows the image. Most portals accept that.
