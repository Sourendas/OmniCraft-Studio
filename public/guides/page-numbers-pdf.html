How to add page numbers to a PDF

Last updated 10 October 2026 · Written by Souren Das

Page Numbers draws a label on each page, counting up from a start number you choose. The label can be a plain number, 1 / N, or Page 1 of N, at the bottom centre, bottom right, or top centre. The stamp is added with pdf-lib in this tab, and the PDF is not uploaded.

Why number a PDF at all

Numbers let a reader say "see page 14" and find it. They show that nothing is missing from a packet, which is why offices like numbered annexures and why a court filing or a tender often requires them. They also help anyone who prints the file and drops the stack. If a document will be discussed, printed, or checked page by page, number it.

When to number

Number last. Merge, split, and reorder first, because the tool counts pages in the file as it is when you stamp it. If you number first and then move pages, the labels lie. The tool does not read numbers already printed in a scan; it only counts pages. If you will also password-protect the file, number before protecting, because an encrypted PDF cannot be stamped here.

Steps

  1. Finish merging and organizing so the page order is final.
  2. Open Page Numbers.
  3. Set Start at. Leave it at 1 for most files.
  4. Choose a Position: Bottom centre, Bottom right, or Top centre.
  5. Choose a Format: 1, 1 / N, or Page 1 of N.
  6. Press Choose PDF files and pick the PDF. Numbering starts as soon as you confirm the picker, and page-numbers.pdf downloads. The page confirms the run, for example Numbered 12 page(s), 1 to 12.
  7. Open the download and check the first page, a middle page, and the last page.

Because the file is processed the moment you pick it, set Start at, Position, and Format before you choose the file. If you change your mind, change the settings and pick the original again.

The settings in detail

The label is 10 point dark grey Helvetica, placed 18 points (about 6 mm) from the edge, which sits inside the margin most printers leave. In the 1 / N and Page 1 of N formats, the second number is the last label on the run, not the count of pages. If you start at 5 on a 10-page file, the pages read 5 / 14 through 14 / 14. That is what you want when a file continues a longer document, and odd when it does not, so leave Start at on 1 unless you mean it.

Start at cannot go below 1. If the cover should carry no number, the clean way is to split the cover off with Split PDF, number the rest, and merge the cover back in front with Merge PDF. The thesis guide walks through that for a title page and front matter.

More than one file

You can pick several PDFs at once. The tool joins them in the order the browser hands them over, numbers the whole run, and downloads one file. That order is usually the order you selected, but not always. If order matters, merge first in Merge PDF, where you can see the list, then number the merged file.

Common mistakes and fixes

  • The new number sits on top of an old printed footer number. Choose Top centre, or Bottom right if the old number is centred.
  • Grey number hard to read on a dark scan. Move it to the other edge, where the page is lighter.
  • A number runs along the side of a page. That page was rotated after it was created, for example with Organize PDF. The label is placed using the page's original orientation. Rotate the source scan upright before it becomes a PDF, or accept the side placement for that page.
  • Could not add page numbers. Encrypted PDFs often fail. Save an unlocked copy first.
  • Numbered twice. Running the tool on a file that already has its labels adds a second set. Start again from the unnumbered file.

What it does not do

The number is drawn on top of the page. It does not move existing content and it does not remove an old number printed in a footer. There are no Roman numerals, no custom text such as "Annexure A-1", and no choice of font, size, or colour. The tool also does not set the PDF's internal page labels, so the page box in your reader still counts from 1. Bookmarks and form fields from the source are not carried into the new file.

FAQ

Can I skip numbering the first page?

Not in one step. Split the first page off, number the rest from 2 (or 1), and merge the cover back.

Can I put numbers on the bottom left?

No. The three positions are bottom centre, bottom right, and top centre.

Is the number selectable text?

Yes. It is drawn as text, so it can be selected and searched.

Does the file get larger?

Only slightly. The font and the labels add a few kilobytes.
