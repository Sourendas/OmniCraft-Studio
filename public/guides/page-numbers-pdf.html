How to add page numbers to a PDF

Page Numbers draws a label on each page from a starting number you choose. Formats are a plain number, 1 / N, or Page 1 of N, at the top or bottom. The stamp is added with pdf-lib in this tab. The PDF is not uploaded.

When to number

Number the file after you merge, split, or reorder. If you number first and then move pages, the labels lie. The tool does not read numbers already printed in a scan. It counts pages in the file. If a cover should stay unnumbered, see the start number note below.

Steps

  1. Finish merge or organize first.
  2. Open Page Numbers and pick the combined PDF.
  3. Choose the start number and the corner.
  4. Download and check the first and last page. A label can sit on top of a footer. If it collides, pick the other edge and export again.

The settings

Position has three choices: bottom centre, bottom right, or top centre. The label is 10 point grey Helvetica, placed 18 points (about 6 mm) from the edge, which sits inside the margin most printers leave. The format is a plain number (3), a fraction (3 / 12), or words (Page 3 of 12). In the last two, the second number is the last label on the run, not the count of pages, so if you start at 5 on a 10-page file the last page reads 14 / 14.

The start number is the label on the first page. It cannot go below 1. If the cover should carry no number, the clean way is to split the cover off with Split PDF, number the rest, and merge the cover back in front with Merge PDF.

More than one file

You can pick several PDFs at once. The tool joins them in the order the browser hands them over, numbers the whole run, and downloads one file named page-numbers.pdf. That order is usually the order you selected, but not always. If order matters, merge first where you can see the list, then number the merged file.

What it does not do

The number is drawn on top of the page. It does not move existing content and it does not remove an old number printed in a footer. On a scan with a dark band at the bottom, grey text can be hard to read, so try top centre. The tool also does not set the PDF's internal page labels, so the page box in your reader still counts from 1.
