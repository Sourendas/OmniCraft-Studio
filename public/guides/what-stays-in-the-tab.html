What “files stay in this tab” means

Last updated: 1 October 2026 · Written by Souren Das, FileTools Kit, Bengaluru. These notes describe the tools on this site, including what they cannot do.

“Files stay in this tab” means the PDF, image, or resume you pick is read as a browser File object and processed by JavaScript on your device. FileTools Kit does not run an upload API that receives those bytes. Closing the tab drops the in-memory copy. It does not delete a download you already saved.

What still leaves the device

Loading the website does. The host (Vercel) can see IP address, user agent, URL, referrer, and time, the way any HTTPS host can. Vercel Web Analytics may record a page view and route. That is not your PDF. Google AdSense may set cookies and measure ads. The publisher id is in ads.txt (pub-4409273905876536). Ad code does not receive file bytes from our servers, because we do not have those bytes.

Fonts and some images on the marketing pages may load from a third party (Google Fonts, Unsplash). That is a request for the asset, not an upload of your document. Details are in the privacy policy and cookie policy.

What stays local

  • The File objects for PDFs and images, until you close or reload the tab.
  • An optional resume draft in localStorage (ftk_resume_v1) if you used the builder and did not clear site data.
  • UI preferences and optional experiment keys (ftk_ab_*).

What this sentence does not mean

It does not mean the site is invisible. It does not mean a download is encrypted on your disk. It does not mean other sites you then upload the result to will keep it private. It does not mean encrypted PDFs will open. It does not mean health numbers or currency examples are professional advice.

A reload is a wipe

Refresh the tab and the File objects are gone. The download in your Downloads folder remains. People lose work by refreshing to “fix” a stall and then looking for the PDF in the page. It is not there. Pick the files again from disk.

Private browsing still processes locally, and it is more likely to drop the resume draft when the window closes. Do not rely on localStorage if you are on a shared computer. Export the PDF and take the file with you.

Extensions can still read the page. A password manager or a screenshot tool is outside this site’s control. “In this tab” is about our servers, not about every extension you installed.
