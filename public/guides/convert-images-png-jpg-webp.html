How to convert PNG, JPG, and WebP

File Converter re-encodes a PNG, JPEG, or WebP through the canvas in this tab and downloads the result. It is the right tool when a form named a format and you have a different one. It does not handle video or HEIC, and it cannot add detail that was not in the source.

Which format

PNG keeps a flat graphic and a screenshot with sharp text. JPEG is smaller for a photo and is the format most email forms still accept. WebP is a good middle when the site says it accepts WebP. Converting a JPEG to PNG will not make the photo sharper. It often makes the file larger.

Steps

  1. Open File Converter.
  2. Pick the image and the format the receiver asked for.
  3. Download and open it. Check a face or a line of text, not only the file size.

If the file is still too big after the format change, resize it in Image Optimizer.

What changes in the file

JPEG and WebP exports are saved at quality 0.92, which looks the same as the source to most eyes but is still lossy. PNG is lossless. Transparent areas turn white in a JPEG, because JPEG has no transparency, so keep PNG or WebP for a logo on a clear background. Camera metadata such as the capture date and GPS location is not copied into the new file. That is useful before you post a photo, and a problem if you needed the date.

Other files the page handles

The same page decodes audio your browser can play and saves it as WAV, a format almost every editor opens. WAV is uncompressed, so a three-minute song can come out at 30 MB or more. It also pulls the text out of a Word .docx and saves it as .txt, or as a basic PDF with the text only. Images, tables, and fonts from the Word file are not kept. TXT, HTML, and Markdown files can be saved as plain text.
