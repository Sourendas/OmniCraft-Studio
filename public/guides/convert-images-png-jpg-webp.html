How to convert PNG, JPG, and WebP

File Converter re-encodes a PNG, JPEG, or WebP through the canvas in this tab and downloads the result. It is the right tool when a form named a format and you have a different one. It is not a pipeline for video, audio, or HEIC, and it cannot add detail that was not in the source.

Which format

PNG keeps a flat graphic and a screenshot with sharp text. JPEG is smaller for a photo and is the format most email forms still accept. WebP is a good middle when the site says it accepts WebP. Converting a JPEG to PNG will not make the photo sharper. It often makes the file larger.

Steps

  1. Open File Converter.
  2. Pick the image and the format the receiver asked for.
  3. Download and open it. Check a face or a line of text, not only the file size.

If the file is still too big after the format change, resize it in Image Optimizer.
