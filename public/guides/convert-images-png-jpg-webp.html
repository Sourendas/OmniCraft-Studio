How to convert PNG, JPG, and WebP

Last updated 10 October 2026 · Written by Souren Das

File Converter re-encodes a PNG, JPEG, or WebP through the canvas in this tab and downloads the result. It is the right tool when a form named a format and you have a different one: a portal that only takes JPG when your screenshot is PNG, or a WebP you saved from a website that an old app will not open. It does not handle video or HEIC, and it cannot add detail that was not in the source.

Which format to pick

PNG keeps flat graphics and screenshots with sharp text exactly, and it supports transparency. JPEG is smaller for photos and is the format almost every email client, form, and old app accepts. WebP is usually smaller than both at a similar look and supports transparency, and it is a good choice when the site says it accepts WebP. Converting a JPEG to PNG will not make the photo sharper; it usually makes the file larger. The longer comparison is in JPG, PNG, or WebP: which file to send.

Steps

  1. Open File Converter.
  2. Drop the images on Drop your Images, Audio, or Documents here, or click to browse. Each file gets its own row.
  3. In Convert to:, pick JPG, PNG, or WEBP for each row. Different rows can have different targets.
  4. Press Convert. Each row shows its progress and then a Download button.
  5. Press Download. The file is named after the original with _converted added, such as screenshot_converted.jpg.
  6. Open it and check a face or a line of text, not only the file size. Clear Queue empties the list when you are done.

If the file is still too big after the format change, resize it in Image Optimizer. Converting changes the container; resizing is what really cuts size.

What changes in the file

JPEG and WebP exports are saved at quality 0.92, which looks the same as the source to most eyes but is still lossy. PNG is lossless. Pixel dimensions stay the same. Transparent areas turn white in a JPEG, because JPEG has no transparency, so keep PNG or WebP for a logo on a clear background. Camera metadata such as the capture date and GPS location is not copied into the new file. That is useful before you post a photo, and a problem if you needed the date, for example to sort holiday photos, so keep the originals.

Typical conversions and what to expect

  • WebP saved from a website to JPG: works, and the JPG is often a little larger. Fine for an app that does not open WebP.
  • PNG screenshot to JPG for a form: much smaller, but small text can get faint halos. Use it if the form demands JPG; otherwise keep PNG.
  • JPG photo to WebP for a website: usually noticeably smaller at the same look.
  • JPG to PNG: rarely useful. The file grows and the JPEG artefacts stay.
  • Logo with transparency to JPG: background becomes white. Choose PNG or WebP instead.

Other files the page handles

The same page decodes audio your browser can play and saves it as WAV, a format almost every editor opens. WAV is uncompressed, so a three-minute song can come out at 30 MB or more. It also pulls the text out of a Word .docx and saves it as .txt, or as a basic PDF containing the text only. Images, tables, and fonts from the Word file are not kept, so this is for getting the words out, not for a faithful PDF of the document. TXT, HTML, and Markdown files can be saved as plain text.

What it will not convert

HEIC (iPhone photos), AVIF, RAW camera files, video, and PDF pages are not image inputs here, unless your browser happens to decode the image format itself. For PDF pages use PDF to JPG; for photos into a PDF use JPG to PDF; for vector logos see SVG vs PNG.

Common mistakes and fixes

  • Unsupported on a row. The browser cannot decode that file. Export it as JPEG from the app that made it.
  • Renaming instead of converting. Changing .png to .jpg in the file name does not convert anything, and some portals detect the mismatch.
  • Expecting a sharper image. Conversion never adds detail.

FAQ

Can I convert many images at once?

Yes. Drop them together, set Convert to: on each row, and press Convert.

Can I choose the JPEG quality?

Not here; it is fixed at 0.92. Image Optimizer has a quality slider.

Does converting resize the image?

No. Dimensions stay the same.
