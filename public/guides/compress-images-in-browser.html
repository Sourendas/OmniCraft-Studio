Compress images in the browser

Image Optimizer resizes and recompresses pictures so they fit an email or a form with a megabyte cap. It uses the canvas API in this tab. Recompression throws detail away. Keep the original file.

  1. Open Image Optimizer and add photos the browser can decode.
  2. Set a max width. 1600 pixels is enough for most screens.
  3. Set JPEG quality around 0.7–0.85.
  4. Download and check faces and text. If text is mushy, raise quality and run again from the original.

You cannot recover detail after a heavy compress. Phone panoramas can stall a tab.
