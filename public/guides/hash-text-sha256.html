Hash text with SHA-256 in the browser

Dev Tools can hash a string with the Web Crypto API in this tab and return a hex digest. FileTools Kit does not send that string to a hashing server we operate.

SHA-256 is a one-way digest. Base64 is encoding, not encryption. Do not treat a single browser hash as a password-storage design.

  1. Open Dev Tools.
  2. Paste the input. Keep secrets off shared screens.
  3. Run SHA-256 and copy the hex output.
