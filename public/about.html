About FileTools Kit

FileTools Kit is a client-side utility suite. Convert, merge, compress, format, and export files in your browser tab using libraries such as pdf-lib, jsPDF, and the HTML5 Canvas API.

FileTools Kit does not run a server that receives your documents or images. The website host still serves HTML, CSS, and JavaScript. Tool-card photos may load from Unsplash.
