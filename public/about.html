About FileTools Kit

FileTools Kit is a free set of twelve utilities that run in your browser tab. The site exists so you can merge a PDF, compress an image, or export a resume without creating an account or sending the file to a processing server we operate.

I built it because many “free PDF” sites ask you to upload a document to a machine you do not control, then surround the download with accounts and paywalls. This project is the opposite shape: the page is a static web app. The file you pick stays in the tab as a File object. Libraries such as pdf-lib, jsPDF, Web Crypto, and the canvas API do the work on your device.
