Reporting a problem with a tool

A useful report says:

  • which page you were on, for example /merge-pdf;
  • your browser and device, for example Chrome on Android or Safari on a Mac;
  • what you expected and what happened instead, including any error message;
  • roughly how large the file was and how many pages or images it had.

Please don't attach the document unless you want a person to read it. The tools work without uploading files, and most bugs can be reproduced from a description or a harmless sample file.

Corrections to a guide

If a guide says something wrong about how a tool behaves, send the page URL and the sentence. I will fix the page and update its date.
